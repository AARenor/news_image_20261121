A 1024×1024 news front page for Saturday 21 November 2026: 52 verified stories from 7 regions and 22 fields, with three illustrated leads, twelve picture cards and 37 numbered one-liners under a huge dated masthead. Made by reading the day's Wikipedia current-events page and wire coverage from Reuters, AP, AFP, Al Jazeera, the BBC, CNBC and others, then drawing fifteen original illustrations and rendering the page with Playwright.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
